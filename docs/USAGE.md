# docs/USAGE.md — 安装、配置与使用说明

> 适用版本 v0.1.0（ER-005 打包验证版）。本文是用户侧配置与备份恢复的权威说明。

## 1. 安装

- 安装包：`release/知行-Setup-0.1.0.exe`（Windows x64，NSIS 安装向导，可选安装目录）。
- 绿色运行：`release/win-unpacked/知行.exe` 可直接运行（不写注册表卸载项）。
- 系统要求：Windows 10/11 x64。运行时依赖已全部内置（Electron 44 + 内置 SQLite），无外部数据库。
- 数据位置：`%APPDATA%\知行\`（数据库 `zhixing.db`，不入安装目录）。

## 2. 首次配置（设置页）

1. **API Key（BigModel）**：到智谱 BigModel 控制台**重新生成**一个 API Key（此前任何渠道出现过的 Key 一律不用），在设置页粘贴并保存——Key 经 Windows safeStorage 加密存储，不回显、不落明文。点「测试连接」验证：明确显示成功或具体原因（鉴权失败 / 余额不足 / 模型不可用 / 限流 / 超时），不会自动切换模型或接口。
2. **模型与接口（多模型兼容）**：默认 BigModel（glm-5.3-flash）。想用其他模型：设置页「模型连接」里把接口地址改为任何 OpenAI 兼容服务的 Base URL（如 `https://api.deepseek.com/v1`、`https://api.moonshot.cn/v1`、本地 `http://localhost:11434/v1`），模型名填对应模型 ID，保存即可，API Key 仍只存一个（填所选服务的 Key）。
4. **Obsidian 导出目录**：默认 `<你的用户目录>\Documents\Obsidian Vault\个人成长\晚间复盘`（从当前用户主目录推导），可修改。日报/周报/月报/年报分别写入对应子文件夹（首次导出自动创建）；导出是单向的，手工修改不会回流、也不会被覆盖。
4. **月度预算**：默认 20 元/月，可调。调用前预占、按实际用量结算；超限自动暂停模型调用（本地记录不受影响）。模型单价默认是**占位价**（未核实），请按控制台实际价格填写并记录核查日期。
4. **提醒窗口**：默认 21:30—23:00，每天最多提醒一次；当天已完成复盘或对话进行中则不打扰；错过不补发、不唤醒电脑。
5. **外观**：浅色 / 深色 / 跟随系统。

## 3. 日常使用

- **晚间复盘**（3—5 分钟）：今晚复盘 → 开始 → 自由讲述 →（最多两个追问，可跳过）→ 收束反馈 → 结束 → 自动生成日报并导出到 Obsidian。随时可深入探讨；点击结束不代表接受建议，只有你明确点「确认」的行动才会登记。
- **只记一句**：忙的时候一句话 + 情绪标记即可，不发起 AI 反馈，照样生成日报。
- **我的记录**：日报按修订版本保存（改一次存一版，不覆盖）；行动候选需显式确认；导出失败可一键重试（只重试导出，不重新调用模型）。
- **小实验**：三个假设选最关键的一个 → 动作/投入/周期（≤7 天）/指标/继续与停止条件 → 明天的第一步；同时最多一个进行中；到点登记实际结果与结论。
- **思想库**：首批 8 张《纳瓦尔宝典》原则卡（默认未启用，逐张确认）；支持粘贴摘录或写个人建议。
- **成长回顾**：周报（周一至周日）/月报/年报在周期结束后自动生成（应用运行且预算允许时）；空周期不生成；日报修订后旧报告标记「过时」，可重新生成（旧版保留）。
- **托盘**：关闭窗口 = 最小化到托盘（首次有解释）；彻底退出请用托盘图标菜单的「退出」。

## 4. 备份与恢复

- **备份**：设置页 →「备份到目录…」→ 选择目录。生成 `zhixing-backup-<时间>.db` 一致性快照（VACUUM INTO，复盘进行中也可安全备份）+ 元数据说明。
- **恢复**：设置页 →「从备份恢复…」→ 选择备份文件。应用先校验（是否本应用的库、schema 版本、数据统计供确认），确认后**重启应用时生效**；当前数据自动留档为 `zhixing.db.before-restore`。
- **注意**：API Key 加密与 Windows 账户/机器绑定，恢复到其他机器后需重新输入 Key。

## 5. 已知限制（v0.1.0）

- 周期报告与对话反馈依赖 BigModel 网络可达；离线时本地记录照常、AI 功能暂停。
- 提醒的系统通知依赖 Windows 通知服务；「已尝试」不等于「已看到」。
- 深色主题下启动瞬间可能有一帧浅色窗口背景。
- 原则卡快照由 AI 辅助摘录自公开站点，建议人工复核原文页（快照内已标注）。
- 未做自动更新；升级请下载新安装包覆盖安装（数据在 %APPDATA%，不受影响）。
