# docs/UI_SPEC.md — 界面规范

> 界面决策变更先修改本文并登记 `docs/DECISIONS.md`。

## 1. 风格基准

参考 AIHOT 仓库提交 `cf8f8d07d68dfa9079becc72b0717a45b33485f3` 的视觉风格（来源与验证状态见 `docs/REFERENCES.md` R-2）。

- 使用本项目自己的产品名称与图标；如复用外部代码，保留原许可声明。

## 2. 色板

| 主题 | 背景 | 强调色 |
|---|---|---|
| 浅色 | 暖白 `#faf9f6` | 青绿 `#176b75` |
| 深色 | `#13191c` | `#12ccd8` |

- 正文主色：墨色 `#202a30`（浅色主题）。
- 细边框卡片、12px 圆角、舒适留白。
- 正文 16—17px。
- 轻量动效；支持系统"减少动画"偏好；支持键盘操作。

## 3. 布局

- 左侧导航 + 右侧内容区；导航项即下方页面清单。
- 空状态、加载态、失败态都必须有明确文案，不留白屏。

## 4. 页面清单

| 页面 | 核心要素 |
|---|---|
| 今晚复盘 | 开始入口、"只记一句"简短模式入口、当日状态 |
| 对话 | 流式消息、追问控制（跳过 / 深入）、结束按钮、状态标签 |
| 我的记录 | 日报列表、修订版本、导出状态 |
| 小实验 | 实验卡片、进行中 / 已结束、观察记录、回访 |
| 思想库 | 原则卡（原文摘录与中文解读区分显示）、来源链接、导入入口 |
| 成长回顾 | 周 / 月 / 年报、实际覆盖范围说明、证据索引 |
| 设置 | API Key（safeStorage）、Obsidian 路径、提醒窗口、预算、主题 |

## 5. 状态规范（强制）

对话与导出必须区分以下状态，禁止用一个"成功"掩盖不同环节：

- 对话：已保存 / 提炼中 / 提炼失败；
- 导出：已导出 / 导出失败（含重试入口）。

## 6. 适配与检查矩阵

- 分辨率：1366×768、1920×1080；系统缩放 125%。
- 主题：浅色、深色。
- 必查项：长文本溢出、空状态、失败提示。
